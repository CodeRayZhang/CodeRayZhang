## 正在打磨

### [RayWork Studio — AI 内容交付工作台](https://github.com/RayXBuilds/raywork-studio)

面向小型内容工作室，将品牌资料整理为可批注、可逐项审核的六模块内容包，支持局部重写、版本记录与审核后导出。Python · FastAPI · SQLite。

[上手指南](https://github.com/RayXBuilds/raywork-studio#快速开始) · [预览版本](https://github.com/RayXBuilds/raywork-studio/releases/tag/v0.1.0) · [产品路线](https://github.com/RayXBuilds/raywork-studio/blob/main/docs/ROADMAP.md)

### [CineMatch — 电影发现与个性化推荐](https://github.com/RayXBuilds/cinematch-recommender)

Vue 3 + TypeScript + Spring Boot 4 + Java 21。包含电影发现、私人片单、推荐实验室，以及可训练、可回退的 ALS 混合推荐。

[运行指南](https://github.com/RayXBuilds/cinematch-recommender/blob/main/docs/deployment.md) · [页面预览](https://github.com/RayXBuilds/cinematch-recommender/tree/main/docs/screenshots) · [评估与局限](https://github.com/RayXBuilds/cinematch-recommender/blob/main/docs/recommendation-model-evaluation.md)

下一步重点：提高当前片库的模型覆盖，补充与真实使用场景一致的评估。现有离线结果尚未超过热门榜，评估口径见上方文档。
